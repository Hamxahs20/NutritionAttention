BRAINROT NUTRITION — PRESENTER DEMO

Upload index.html, content_facts.html and attention_nutrition.html together to the same GitHub Pages directory.

1. Open index.html on Chrome.
2. Open the feed and dashboard in two windows in the SAME Chrome profile and on the SAME GitHub Pages origin.
3. Move the dashboard to a second monitor. The dashboard refreshes every 15 seconds.
4. In Content Facts, click View Content, watch, and tap Next ↑ or swipe up. The full catalog of 8 reels rotates before repeating.
5. Look for the green Logging 0s indicator. It records immediately and updates every 2 seconds.
6. Clear demo in the presenter toolbar to erase current device's viewing records.

Important: scoring is illustrative, based on demo content labels and viewing durations. It cannot diagnose addiction or measure actual personal attention span. The attached video files are sample clips, not independently classified videos. Cross-device connection needs a backend.
